# 📧 Email Spam Classifier

## 🚀 Project Overview
The Email Spam Classifier is a Machine Learning-based application designed to classify messages as **Spam** or **Not Spam**.

With the increase in unwanted messages, this system helps in identifying spam efficiently using Natural Language Processing (NLP) techniques and a trained classification model.

---

## 🎯 Objectives
- To automatically detect spam messages  
- To reduce unwanted and harmful content  
- To demonstrate real-world application of Machine Learning  
- To build a simple and effective classification system  

---

## 💡 Key Features
- 🔍 Spam message detection  
- 🤖 Machine Learning-based prediction  
- 🧠 NLP-based text processing  
- ⚡ Fast and efficient system  
- 🌐 Simple user interface  

---

## 🛠️ Technologies Used
- Python  
- Flask  
- Scikit-learn  
- Pandas  
- NumPy  
- HTML & CSS  

---

## ⚙️ System Workflow
1. User inputs a message  
2. Text is preprocessed (cleaning, removing unwanted characters, etc.)  
3. Text is converted into numerical form using vectorization  
4. Machine Learning model predicts the result  
5. Output is displayed as:
   - 🚨 Spam Message  
   - ✅ Safe Message  

---

## 📊 Example Output
- Input: "Win money now!!! Click here!!!"  
  👉 Output: 🚨 Spam Message  

- Input: "Are you coming to class today?"  
  👉 Output: ✅ Safe Message
