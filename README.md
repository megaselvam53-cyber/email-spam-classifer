# Email Spam Classifier

This project is a machine learning based web application used to classify text messages as Spam or Not Spam.

## Features
- Predicts whether a message is spam or safe
- Web interface using Flask
- Machine learning model for text classification
- Simple and user-friendly design

## Technologies Used
- Python
- Flask
- Scikit-learn
- HTML/CSS
- Pandas
- TF-IDF / CountVectorizer

## How to Run
1. Clone the repository
2. Install required packages using:
   pip install -r requirements.txt
3. Run the application:
   python app.py
4. Open in browser:
   http://127.0.0.1:5000

## Project Output
- Spam message → 🚨 Spam
- Normal message → ✅ Safe
